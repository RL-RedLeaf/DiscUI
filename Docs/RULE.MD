# 飞盘游戏DiscUI规则
## 比赛基本信息
### 队伍人数：
每队通常3至7人上场，正式比赛中每队最多7人 

### 场地：
长方形场地，标准尺寸为 x = (1110+540*2) px, y = 1920px，两端各有540px深的得分区 
发盘区位于各自得分区前540px

### 比赛目标：
将飞盘传入对方得分区并被队员接住即可得分 

### 比赛形式：
比赛由若干回合组成，每回合以得分结束，先得到15分者获胜

## 传盘与接盘
### 传盘：
持盘者不能跑动，必须在原地传盘，可向任意方向传给队友 

### 持盘时间：
持盘者有0.2秒时间决定传盘方向，超时即为犯规

### 接盘：
接盘者需准确判断飞盘轨迹和速度，进行接盘 

## 得分与失误
### 得分：
进攻方在对方得分区接住飞盘得1分 

### 失误：
传盘失败（出界、掉地、被对方截获）即视为失误，防守方获得盘权 

## 犯规与安全
### 无身体接触：
比赛禁止身体接触和阻挡跑动，发生接触判为犯规
